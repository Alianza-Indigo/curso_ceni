# Formatos NOM-035 (F-16 a F-18)

Plantillas de cumplimiento de la **NOM-035-STPS-2018** con enfoque neuroafirmativo,
para usarse junto con el Módulo 5 del Curso CENI.

| Código | Archivo | Uso |
| --- | --- | --- |
| **F-16** | `F-16_Politica_Prevencion_Riesgos_Psicosociales_NOM-035.docx` | Modelo editable de política de prevención (base Guía de Referencia IV, numeral 5.1). Sustituya el texto entre corchetes. |
| **F-17** | `F-17_Checklist_Cumplimiento_NOM-035.xlsx` / `.pdf` | Checklist de las obligaciones de la norma, escalonadas por número de trabajadores. |
| **F-18** | `F-18_Anexo_Neurodivergente_Instrumento.xlsx` / `.pdf` | Anexo neurodivergente (8 reactivos, escala Likert). **Complemento** del cuestionario oficial (Guía II o III), no un sustituto. |
| **F-19** | `F-19_Cuestionario_Guia_II_NOM-035.xlsx` / `.pdf` | Cuestionario **oficial** Guía II (16–50 trabajadores, 46 reactivos). El Excel calcula el puntaje y el nivel de riesgo automáticamente. |
| **F-20** | `F-20_Cuestionario_Guia_III_NOM-035.xlsx` / `.pdf` | Cuestionario **oficial** Guía III (más de 50 trabajadores, 72 reactivos), con evaluación del entorno organizacional. El Excel calcula puntaje y nivel de riesgo. |

Con **F-19 / F-20** la organización cumple el corazón de la norma (identificación
y análisis); **F-18** se aplica junto a ellos como complemento neuroafirmativo, y
**F-16 / F-17** cubren la política y el checklist de cumplimiento.

En los Excel, marque una opción por reactivo en la columna "Respuesta"; el puntaje
(normal o inverso según el reactivo) y el nivel de riesgo se calculan solos.
Las versiones Excel/Word son editables; las PDF son para impresión y llenado.
Fundamento: NOM-035-STPS-2018 (DOF 23/10/2018). Alianza Índigo Neurodivergente A.C.
